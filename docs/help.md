# Getting help

## Try these first

- **"You don't have access" / "Permission denied"** — your account can only open the services on the
  [Services](services.md) page. If it's one of those, your account may still need to be switched on —
  [message @admin@](#still-stuck).
- **Stuck in a sign-in loop, or signed in as the wrong person** — sign out at <https://@auth@>, close the tab, and try
  again. A private/incognito window is a quick way to test.
- **Lost your passkey** (new phone, cleared browser) — sign in by typing your username or email instead. You'll get a
  code by email. Then add a new passkey from your [account settings](account.md#managing-your-account).
- **Didn't get a sign-in code** — check your spam folder. Codes come from `authentik@@domain@`.
- **An app won't connect** — double-check the server address against the [Services](services.md) page. It must start
  with `https://`.
- **Everything is down at once** — the server is probably restarting for updates, which happens automatically overnight.
  Give it ten minutes.

## Still stuck?

Message @admin@. It helps to say:

- which service, and whether you're using a browser or an app (and which device);
- what you were trying to do;
- what happened instead — a screenshot of any error is perfect.
