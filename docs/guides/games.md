# Game servers

Game servers don't use your [account](../account.md) — you connect to them straight from the game.

## Minecraft

These worlds run on **Minecraft: Java Edition** (the PC/Mac version, not Bedrock/console/phone).

--8<-- "minecraft-worlds.md"

### Joining

1. **Get whitelisted first.** Only approved players can join. Send @admin@ your **Minecraft username** and ask to be
   added.
2. In Minecraft, go to **Multiplayer** → **Add Server**.
3. Paste the address from the table above into **Server Address** (no port number needed) and click **Done**.
4. Double-click the server to join.

!!! note "Version and mods"

    Your game needs to match the world's Minecraft version — if you see **"Outdated client"** or **"Outdated
    server"**, that's the problem. Some worlds are modded; a plain game joins the unmodded ones fine, but ask @admin@
    which version and mods a world needs before joining a modded one.
